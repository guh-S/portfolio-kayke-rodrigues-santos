## 📖 Sobre o Projeto

Este projeto foi desenvolvido com o objetivo de praticar conceitos básicos de **Segurança da Informação** utilizando Python.

O sistema analisa senhas digitadas pelo usuário e verifica se elas seguem boas práticas de segurança, como:

* ✔️ Quantidade mínima de caracteres
* ✔️ Letras maiúsculas e minúsculas
* ✔️ Números
* ✔️ Caracteres especiais

Ao final, a senha recebe uma classificação:

* 🔴 Fraca
* 🟡 Média
* 🟢 Forte
